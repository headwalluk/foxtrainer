# Security model

> **Draft.** This page records the guarantees foxtrainer is designed to keep. It will be
> expanded and checked against the implementation before 1.0.

## Privileges

- foxtrainer runs as you and never asks for root or administrator rights.
- It writes only to your Firefox profile folders and its own config, cache and state folders.
  It never writes to Firefox's install folder or uses system-wide policies.

## What it changes in a profile

- `user.js`: fully generated by foxtrainer. Written atomically with owner-only permissions (0600).
- `prefs.js`: only entries foxtrainer itself set earlier are removed. Nothing else is changed.
- Spellcheck dictionary add-ons, where the operating system has no system dictionaries.
- Both files are backed up before every write.

It never reads or changes bookmarks, history, passwords, cookies or other browsing data.

## Concurrency

foxtrainer will not modify a profile that Firefox is using. It takes Firefox's own profile lock
for the duration of an apply, so Firefox cannot start on that profile part-way through.

## Network

- Upstream pref files are downloaded from pinned commit URLs and verified against sha256 hashes
  in the catalogue before use. A mismatch is an error, never a warning.
- Downloads are cached so `apply` can run offline from the last verified copy.
- No telemetry. foxtrainer sends nothing about you or your browser anywhere.
